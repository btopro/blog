For 6 years I've gotten the privileged of teaching web development. Each year there is a lecture I usually refer to as either "guest speaker" or "the lecture" and in it I detail the path from the students in the audience to.. well.. me. It's not to be full of myself, though other personas I've generated are great at that, it's because they genuinely are often looking for direction in life and so it's a "hero's story" of how I found my own direction.

Taking this concept and applying it to how I provide context to my agents I work with, I've developed [_WORLDVIEW_.md](https://github.com/haxtheweb/praw/blob/main/WORLDVIEW.md) [](https://github.com/haxtheweb/praw/blob/main/WORLDVIEW.md). Worldview is my worldview, that I give the agent to become me even further. How I've gone about building a digital version of myself that I can scale to attack society level problems (because yes, publishing is... society level).

*   All code I've written for haxtheweb is indexed by the agent for quick reference including how our schema works, how we envision making blocks, how the tooling works and how all the backends work
*   _WORLDVIEW.md_ is built off of the agent ingesting this website, which contains all of my writing over the last 16+ years that I've blogged (good thing I maintained and moved all the posts to hax...)
*   _My thesis from my MS work called [Information Altruism](https://github.com/haxtheweb/praw/blob/main/thesis-bryan-ollendyke-information-altruism.pdf)_
*   All issues open and closed in our issue queue, as json based pulls
*   haxtheweb.org's web content (a hax site, about hax)
*   multiple OER courses written in HAX as source; not for the content but to learn how people write content with HAX to more appropriately suggest blocks

If I could pull down video and other presentations to teach it how I speak as opposed to write, I would. the goal is to make the agent me in every way. Now, when I ask how we attack features to improve the platform, it responds in ways that mirror the more activist aspects of my development.

I've already started having very different prompting conversations with the enhanced worldview agent. Context is steeped in worldview, not just what we could do but should do, how to do it, and framing in a way that is about reducing costs and increasing access to publishing.

Approaches for a publishing revolution. Or at least more interesting prompt responses like the following:
